GIFT WEBSITE — QUICK EDIT

1. Buka index.html untuk mengubah nama, ucapan, timeline, dan surat.
2. Ganti foto1.jpg, foto2.jpg, foto3.jpg dengan foto kamu.
   Nama file harus tetap sama agar langsung terbaca.
3. Opsional: masukkan lagu MP3 bernama music.mp3 ke folder ini.
4. Buka index.html di browser untuk preview.
5. Untuk dijadikan link gratis, upload seluruh isi folder ke GitHub Pages.

Catatan:
- Website sudah responsive untuk HP.
- Musik biasanya baru bisa berjalan setelah interaksi pengguna karena aturan autoplay browser.
